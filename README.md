# CSS Positioning Guide

A beginner-friendly educational resource explaining CSS Positioning, its different values, and how to use them to control the placement of elements on a webpage.

## 📚 About This Project

This project is a structured lesson note designed to help beginners understand CSS Positioning through clear explanations, practical examples, and hands-on exercises.

It explains how CSS positioning works and how developers use it to create modern webpage layouts and user interface elements.

## 📖 Topics Covered

- Introduction to CSS Positioning
- Understanding the `position` property
- The `top`, `right`, `bottom`, and `left` properties
- Static Positioning
- Relative Positioning
- Absolute Positioning
- Fixed Positioning
- Sticky Positioning
- Understanding `z-index`
- Differences between positioning values
- Common positioning mistakes
- Practical examples and code breakdowns
- Class exercises and practical assignment

## 🛠️ Technologies Used

- HTML5
- CSS3

## 🎯 Learning Objectives

By studying this guide, learners should be able to:

- Understand how CSS positioning works.
- Identify and explain the five CSS position values.
- Position elements relative to their parent containers.
- Create overlapping elements using absolute positioning.
- Build fixed and sticky navigation elements.
- Understand stacking order using `z-index`.
- Apply positioning techniques in practical webpage designs.

## 🚀 How to Use

1. Clone or download this repository.
2. Open the HTML file in your browser.
3. Read through each topic and study the code examples.
4. Practise the exercises and complete the practical assignment.

## 👩‍💻 Intended Audience

Beginner web development students and anyone learning HTML and CSS.
